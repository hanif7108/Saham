## Fase 6 — Eksperimen Stabilitas Edge (malam)

- **Multi-seed classifier h10 (10 seed × 11 kuartal)**: return
  −48,9%..+92,3% antar model kembar-statistik (median −1,5%); ensemble
  −17%/Sharpe 0.03; IC ~0.017. **Kesimpulan: edge classifier h10 tak
  terbedakan dari nol; "+39%" produksi = undian menguntungkan. Ensemble
  GAGAL uji → tidak diadopsi.** Kebijakan baru: shadow dipertahankan
  sampai track record live ATAU IC_IR walk-forward ≥ 0.3.
- **Multi-seed rank h10/h20 (kriteria pre-registered)**: sinyal rank
  NYATA & stabil (IC_IR 0.27±0.03, sebaran sempit); **h20 = ekonomi
  terbaik yang pernah diuji (+10,3% ensemble, DD −22%)** namun gagal
  tipis ambang (0.272 < 0.3) → disiplin dipegang, tidak diadopsi.
  **Plafon fitur teknikal-saja ≈ IC_IR 0.28.**
- **Roadmap riset**: uji ulang rank-h20 multi-seed saat fitur fundamental
  point-in-time & cross-sectional 844 ticker matang di datalake
  (± beberapa bulan).
- **Pelajaran infrastruktur rig** (terdokumentasi di README rig):
  Python 3.14 system segfault saat training LightGBM → wajib 3.12 via uv;
  segfault OpenMP teratasi dengan num_threads=16 + OMP_STACKSIZE=256M;
  proses panjang WAJIB `systemd-run --user` (setsid tetap mati saat
  session-scope ssh ditutup).
